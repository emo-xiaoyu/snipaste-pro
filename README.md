# Pasty

Pasty 是一个面向 Windows 的本地剪贴板小工具：自动记录文本、图片和文件，支持搜索、固定常用内容、自定义保存指令/网址/话术，并通过全局快捷键快速呼出。

## 复制记录

- 自动区分文本、网址、命令、图片和文件。
- 保留网页 HTML 富文本，再次粘贴时尽量恢复格式。
- 可记录复制来源应用和窗口，并按来源搜索。
- 同一内容自动合并，累计复制次数。
- 默认跳过密码、令牌、银行卡号等敏感内容。
- 右下角显示不抢焦点的短暂保存提示。
- 设置页可独立开关捕获类型、来源、去重、敏感保护和历史上限。
- 粘贴使用启动时预热的 Windows 辅助进程，本地默认只等待 35ms；识别到 UU远程、ToDesk、向日葵、RDP 等远控窗口时自动切换为可配置的同步等待。

## 使用方式

- 默认按 `Alt+V` 呼出窗口。
- 按 `Alt+Shift+S` 冻结鼠标所在屏幕，并直接在鼠标光标处预选约 `520 × 320` 的区域，不会自动框选整扇前台窗口。左键按下前预选框会跟随鼠标并在屏幕边缘自动贴边；左键拖动后改为自定义选区，仍可重新框选、从八个方向调整尺寸；方向键移动 1 像素，`Shift + 方向键` 调整尺寸。
- 自动框选只是起始建议：在冻结画面的任意位置按住左键拖动，都会从当前鼠标位置重新画选区，即使鼠标位于旧选区内部；拖动边角调整大小，`Alt + 拖动` 移动整个选区。
- 截图时实时显示鼠标像素的 HEX / RGB，并支持画笔、箭头、矩形、椭圆、颜色、线宽、撤销和重做。`Enter`、双击或 `Ctrl+C` 复制并完成，`F4` 或 `Ctrl+P` 会复制最终截图并固定到桌面，右键逐步返回，`Esc` 取消。
- `F4` 新建的贴图使用应用启动时预热的隐藏窗口，默认立即出现在原截图位置，并按当前显示器缩放比例还原成相同桌面尺寸；未手动缩放时没有留白、边框或图片压缩，可覆盖补全截图前的原页面。之后可拖动移动，也可直接使用鼠标滚轮，以光标位置为中心等比例放大或缩小。
- 贴图边缘带有轻微虚影和细线，方便从原页面中区分出来；虚影使用透明窗口边缘承载，截图内容本身的位置与尺寸不变。
- 截图编辑器会在应用启动时预热；呼出时不再查询前台窗口边界，Pasty 界面已隐藏时也不增加固定等待。`F4` 直接从冻结原图和标注生成截图，不再等待两帧选区隐藏动画。
- 截图 PNG 与历史索引采用异步原子持久化，贴图显示不再等待磁盘写入；历史缩略图会缓存，避免每次 F4 都重新编码全部图片。
- 按 `Alt+Shift+P` 将鼠标附近区域直接截图并固定到桌面。
- 按 `Alt+Shift+V` 打开截图历史，使用 `↑` / `↓` 切换，按 `Enter` 将当前截图固定为可拖动、可缩放的桌面贴图。
- 桌面贴图只在本次应用运行期间保留；重启后不会自动铺回桌面，但截图历史仍会保留，可随时重新固定。
- 桌面贴图上静止长按鼠标左键可进入离线文字模式；随后像网页一样拖动选择局部中文、英文、数字和标点，蓝色高亮后按 `Ctrl+C` 或点击“复制”只复制当前选区。`Esc` 或“完成”返回贴图拖动模式，图片不会上传。
- 输入关键词搜索，按 `↑` / `↓` 选择，按 `Enter` 粘贴到刚才使用的应用。
- 在“常用”中保存长期使用的指令、网址、文本或当前剪贴板图片。
- 点击右下角明确标注的“快捷键”按钮即可修改应用唤出、截图、快速截图贴桌面和截图历史快捷键；这些选项位于设置页第一屏。
- 历史数据保存在 `%APPDATA%\pasty-clipboard`，图片只保存在本机。

## 本地运行

```powershell
npm install
npm run build
npm run start
```

开发时可运行：

```powershell
npm run desktop
```

自动回贴依赖 PowerShell 7（`pwsh.exe`）。如果自动按键不可用，内容仍会写入系统剪贴板。

## 构建 Windows 安装包

```powershell
npm run build:desktop
```

正常完成后安装包会出现在 `release` 目录。当前机器上的 Electron Builder 在 `packaging` 阶段长时间停滞，因此本次交付未生成安装包；源码版和生产构建可以正常运行。
